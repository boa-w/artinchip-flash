# 擦写模式对照（数据擦写 / eFuse）

AiBurn 数据擦写页的完整功能对照：进入擦写模式 + 六个操作，
逐项给出官方等价路径、本工具状态与证据（或阻塞点）。

> 约定同《eFuse 分析与实现》：标“已验证”的均可在本机复现
> （`C:\Program Files\AiBurn\upgcmd.exe` V2.1.0 +《AiBurn 使用指南》）；
> 其余为推断并明确标注。

## 1. 进入擦写模式

1. 芯片先进入 **BROM 升级模式**（空片上电直进；有升级键则按键+复位；
   有应用/BootLoader 命令行则输入 `aicupg`）。
2. AiBurn 确认 BROM 模式后，数据擦写页的**进入擦写模式**按钮可用
   （仅 BROM 下可用；手册 §2.3.1）。
3. 进入后工具自动检测启动存储设备，填入**存储设备**下拉框
   （二进制证据：`Failed to get boot device list`——下拉内容来自设备查询）。
4. 完成后**手动重启**退出（另见 `bdreboot` 透传）。

二进制旁证：`Failed to enter erase mode, boot stage:`——进入有 boot
stage 门控；`bin/fw_d12x.bin`（23KB）、`fw_d13x.bin`（41KB）、
`fw_d21x.bin`（36KB）随包（进入阶段可能下载对应 SoC 固件，待抓包确认）。

## 2. 会话结构（重建，线格式未知）

```
进入擦写模式 → bdopen → [bdcfg / get boot device list / get efuse part list]
  → bderase / bdread / bdwrite / bd_efuse_read / bd_efuse_write
  → bdclose / bdreboot / 手动重启
```

设备侧动词均出自二进制字符串（`bdopen %u`、`bdcfg mmc 0x%x…`、
`bdread/bdwrite %u 0x%x 0x%x 0x%x`、`bderase %u boot|%u 0x%x 0x%x`、
`bdclose %u`、`bdreboot`、`bd_efuse_read/write`、`bd_auz_*`、`bd_mmc_*`），
另有 AUZ Meta、key/workbuffer 分配与加解密字符串，表明 bulk 会话含授权
与缓冲协商。**UPG 线包格式未知，不得据此手写原生实现。**

CLI 有效性探针（无设备，`upgcmd <cmd>`，规律：未知命令报
`Command '...' not found!`，合法命令进设备打开流程）：

| 探针 | 结论 |
|---|---|
| `bdopen`、`bdcfg`、`bdread`、`bdwrite`、`bderase`、`bdclose`、`bdreboot` | 合法顶层命令 |
| `bd`、`dataerase`、`agent` | 非法（not found） |
| 带参/缺参调用（如 `bdread a b`、`bderase x`） | 均先进设备打开（参数校验在后，无硬件不可知参数形状） |

因此除零参的 `bdreboot` 外，`bd*` 的 CLI 参数顺序无法确认，不做透传。

## 3. 六操作映射表

| AiBurn 操作 | 参数（手册 §2.3） | 官方等价 | 本工具状态 |
|---|---|---|---|
| 进入擦写模式 | BROM 下点击按钮 | —（无 CLI 等价） | 未实现（待抓包，见 §2） |
| 擦除 Boot | 选存储设备→执行；工具自动找 BootLoader 区 | `bderase %u boot`（设备侧） | 未实现（同上） |
| 读取数据 | 设备 + Flash 偏移 + 长度 + 保存目录；SPINOR 无对齐要求但不出界，SPINAND 按 NAND Page 对齐，eMMC/SD 按 512 对齐 | `bdread`（设备侧） | 未实现（同上） |
| 擦除数据 | 同上（目录项疑似笔误）；SPINOR/SPINAND 按物理块对齐，eMMC/SD 按 512 对齐 | `bderase`（设备侧） | 未实现（同上） |
| 写入数据 | 设备 + 偏移 + 长度 + 数据文件；**要求空间已预擦除**；SPINOR 按 256 对齐，SPINAND 按 Page 对齐，eMMC/SD 按 512 对齐 | `bdwrite`（设备侧） | 未实现（同上） |
| eFuse 读取 | 选区 + 区内字节偏移 + 长度（不超区上限）；hex 显示 | `bdefuse list/select/read/dump` | **已实现**（工具页透传，见《eFuse 分析与实现》） |
| eFuse 烧录 | 选区 + 偏移 + 按字节序的 hex；OTP（0→1，可重复写 1） | `bdefuse write/writehex`、`auzwritefuse` | **已实现**（同上） |
| 退出擦写模式 | 手动重启 | `bdreboot` | **已实现**（零参透传） |

`bdcfg mmc`（MMC 配置）与 `bd_auz_*`（授权流）用途与时机未知，一并待抓包。

## 4. 原生实现需要的证据

与《eFuse 分析与实现》§6 相同：usbpcap/usbmon 抓 AiBurn 点击
进入擦写模式、`bdefuse read`、读取数据（小长度）、擦除 Boot 四个动作，
看 CBW 载荷 `UPGC` 后的 CMD 字节（`src/protocol/commands.rs` 之外的新字节
即候选）与 `SET_UPG_CFG` 模式字节。Luban-Lite 公开 bootloader 源码中无
`bd*`（research_notes 备查），可能位于未公开的 U-Boot fork 或 BROM。

# 使用指南

`artinchip-flash` 是 ArtInChip SoC 的跨平台烧录工具，提供命令行（CLI）和图形界面（GUI），
与官方 AiBurn 的烧录流程兼容。本指南对照官方《AiBurn 使用指南》v2.1.0 编写，
差异处见《与 AiBurn 功能对照》。

## 安装

### 系统要求

- Windows 10+ / Ubuntu 22.04+ / macOS 11+
- Rust 1.70+（仅自行编译需要）

### 安装包

GitHub Releases 提供以下包（`nightly` 为每日构建，`v*` 为稳定版）：

| 系统 | 推荐安装 | 便携包 |
|---|---|---|
| Windows x64 | `artinchip-flash-windows-x64-setup.exe`（安装向导）或 `.msi` | `.zip` |
| Linux x64 | `.deb`（自动装 udev 规则和桌面项） | `.tar.gz` |
| macOS arm64 | `.pkg`（GUI 进 `/Applications`，CLI 进 `/usr/local/bin`） | `.tar.gz` |

### 驱动 / USB 权限

- **Windows**：GUI 点 Driver，或执行 `artinchip-flash install-usb-access`，
  通过 `pnputil` 安装 WinUSB 绑定（VID `33C3` / PID `6677`，需 UAC 提权）。
  注意：本工具生成的是未签名 INF，部分开了驱动强制签名的系统需按官方手册 §4.1 临时禁用。
- **Linux**：同上命令安装 udev 规则后重新插拔设备；也可手动写入
  `/etc/udev/rules.d/99-artinchip-flash.rules`。
- **macOS**：一般无需驱动。如打开设备成功但传输立即超时，关闭其他 USB 调试工具后重连。

## 进入烧写模式

与官方一致，任选其一（详见官方手册 §2.1.1）：

- 空片上电直进；短接烧录引脚（PA0）到地；按住 U-Boot 键上电/reset。
- 运行中系统执行 `aicupg gotobl`；Bootloader 控制台执行 `aicupg uart 0`（UART）。
- 已进 Linux 且 ADB 可用：设置里打开 ADB 兼容扫描，点烧录会自动经 ADB 进入升级模式。

UART 下工具默认会自动尝试进入升级模式（发送 `aicupg gotobl` / `aicupg uart 0`，
必要时复位开发板），可用 `--no-enter-upg`（CLI）或复选框（GUI）关闭。

## CLI 用法

```
artinchip-flash scan                     # 扫描 ArtInChip USB 设备
artinchip-flash usb-list                 # 列出 libusb 可见的全部 USB 设备
artinchip-flash serial-list              # 列出可用于 UART 升级的串口
artinchip-flash info                     # 查询已连 USB 设备信息
artinchip-flash info <固件.img>          # 解析镜像头和 META 条目
artinchip-flash info --uart /dev/ttyUSB0 # 经 UART 查询设备
artinchip-flash burn <固件.img>          # 经 USB 烧录
artinchip-flash burn <固件.img> --no-reset
artinchip-flash burn <固件.img> --uart /dev/ttyUSB0
artinchip-flash burn <固件.img> --uart auto --speed 1500000
artinchip-flash uart-monitor /dev/ttyUSB0 [--enter-upg]
artinchip-flash env-check [固件.img]     # 环境自检（含冲突服务检测）
artinchip-flash install-usb-access       # 安装 USB 访问支持
artinchip-flash stats [--clear]          # 按天烧写统计（成功/失败/取消）
artinchip-flash sd-list                  # 只读列出物理磁盘（启动卡目标确认，不写卡）
artinchip-flash update [--channel stable|nightly] [--open]
```

全局标志：`--verbose`（传输层 CBW/CSW、UART 组帧日志，也可用环境变量
`ARTINCHIP_FLASH_VERBOSE=1`）、`--json`（`scan`、`usb-list`、`serial-list`、
`stats`、`sd-list`、`update` 输出机器可读 JSON，便于脚本调用）。
`env-check` 输出新增冲突服务段（Windows 解析 `sc query` 找 VMware/VirtualBox
USB 占用并给出手动 `sc stop/config disabled` 命令，不自动停用；
Linux/macOS 给等效释放提示）。

### 烧录选项

| 选项 | 说明 |
|---|---|
| `--uart <串口\|auto>` | 经串口烧录，`auto` 探测全部串口 |
| `--baud <波特率>` | 初始波特率，默认 115200 |
| `--speed <波特率>` | 烧录前经 `SET_UART_ARGS` 协商更高速率 |
| `--no-enter-upg` | 关闭握手失败时自动进入升级模式 |
| `--no-reset` | 烧录后不复位设备 |
| `--force-upgrade` | 实验性强制升级（`BURN_IMG_FORCE`，与复位互斥，烧后不复位）；需设备端开启强制升级开关（官方手册 §2.1.4），无硬件验证 |
| `--erase-all` | 烧录前经官方 `upgcmd flasherase` 整片擦除；需 `--upgcmd-path`（Windows 默认取 `C:\ArtInChip\AiBurn\upgcmd.exe`） |
| `--erase-media <ID>` | 擦除介质 ID，缺省取镜像头 `media_dev_id` |
| `--upgcmd-path <路径>` | 官方 `upgcmd(.exe)` 路径，供 `--erase-all` 使用 |
| `--log-file <路径>` | 烧录事件日志另存到文件（控制台输出不变） |

UART 为停等式组帧传输（短帧 `SOH` / 长帧 `STX`，CRC16-CCITT），比 USB 慢；
适配器支持时 `--speed` 可明显缩短烧录时间。
串口波特率建议取官方支持的 115200 / 921600 / 1M / 3M。

烧录中按 `Ctrl+C` 可中止（在当前数据块边界停下，设备保持升级模式，可直接重试；
CLI 以退出码 130 标识“用户取消”）。进度行附带实时速率与用时
（如 `Overall: 12345/67890 (18.2%) 2.31 MiB/s [00:07]`），结束时打印总耗时与平均速率；
`--json` 的进度事件另带 `elapsed_secs` / `rate_bps` 字段，便于脚本采集。

## GUI 用法

```sh
cargo run --bin artinchip-flash-gui
```

### 烧录页（镜像 + 分区 + 烧录单页）

与官方 AiBurn 一致，打开→核对→烧录全流程在同一页内完成，
分三个可折叠分区（均默认展开，可自行收起），内容区可滚动，
日志固定在底部：

- 传输方式下拉：USB 或串口（UART），串口模式可配串口号、初始波特率、最高波特率，
  内嵌串口监视器（查看输出、发送命令、一键进入升级模式）。
- 设备下拉：选择 USB 设备（显示就绪/未就绪状态）；未就绪设备会给出恢复建议。
- **镜像区**：镜像路径输入、浏览、历史记录（`img_history.txt`，上限 50 条）；
  完整镜像头表格（魔数/平台/产品/版本/介质等 12 项）；解包全部组件到目录
  （未加载镜像时禁用）。
- **分区区**：勾选要烧录的 `image.target.*` 组件（`spl`/`env`/`os` 默认选中），
  其余组件（updater、`image.info`）按 AiBurn 流程自动处理；分区栏显示
  `名@介质`（如 `spl@spi-nand`，updater 项为 `ram`）。
- **烧录区**：总进度 + 当前组件进度；下方状态行显示用时、实时速率与已发/总量；
  烧录/停止按钮；自动烧录、ADB 兼容扫描、读取设备日志复选框；
  全片擦除 / 强制升级（勾选后分别在烧录前经 `upgcmd flasherase` 擦除、
  以 `BURN_IMG_FORCE` 模式烧录且不复位，实验性，需设备端开启强制升级开关）。
- 日志窗：高度可拖动调整（像 VSCode 终端那样拉分隔条），文本可框选复制；
  `复制日志` 一键全量进剪贴板，`保存日志` 落盘到
  `logs/artinchip-flash-<时间>.log`（UTC，可另存），`清空` 清屏（内存上限 1500 行）。
- 停止按钮：烧录中可随时中止（当前块完成后停下，设备保持升级模式，可直接重试）。

### 工具页（高级）

- `upgcmd` 兼容后端：配置官方 `upgcmd(.exe)` 路径后，可运行全部 33 个官方命令
  （设备列表、镜像信息、解包、升级、内存读写、分区导出、整片擦除、RAM 启动、
  JTAG 解锁、`bdefuse` eFuse 读写、授权烧录、`bdreboot` 等），支持 `--dev bus:port`（指定设备）、
  `--uart COMx`、`--baudrate`（最高波特率）透传，以及 `--verbose/--log/--progress`。
  eFuse 命令语法见《eFuse 分析与实现》。
- 环境检查、驱动安装、打开官方手册（需配置 AiBurn 兼容目录）。环境检查含冲突
  服务检测（见上）。物理磁盘只读枚举按钮用于启动卡写前核对目标盘（不写卡，
  见《启动卡设计》）。

> 正常镜像解析与在线烧录不需要该目录；它是官方遗留命令的应急通道。

### 设置页

- 数据目录、`AiBurn` 兼容目录、语言（简体中文/English）、超时、重试。
- 自动烧录、ADB 扫描、读取设备日志、详细日志开关。
- **烧写统计**：按天成功/失败/取消 + 成功率表格，每次烧录自动记一笔，
  支持清空；数据在 `burn_stats.json`，损坏按空统计加载。
- **检查更新**：通道（stable/nightly）、开机自动检查、立即检查、打开下载页，
  并标注当前是便携包还是系统安装。
- 加载/保存配置。配置兼容官方 `AiBurn.ini` 键
  （`image_path/auto_burn/show_statistic/is_verbose/retry_cnt/db_inited`）。

## 配置文件

GUI 配置保存在各平台用户配置目录（`config.ini`），同时兼容读取官方
`AiBurn.ini`（若存在）。镜像历史保存在同目录 `img_history.txt`。
烧写统计保存在同目录 `burn_stats.json`（`stats` 命令与设置页共用）。

## 常见问题

1. **扫描不到设备**：先确认已进升级模式（见上），再查驱动/udev，
   换直连线材，关闭虚拟机 USB 服务等干扰源。
2. **Windows 驱动装不上**：杀毒软件拦截、驱动强制签名（参考官方手册 §4.1）。
3. **UART 握手无应答**：确认是控制台串口（115200 8N1）、设备独立供电
   （D12x 除外 USB 供电会被识别成 USB 设备）、尝试复位开发板。
4. **烧录失败**：核对镜像与板型/介质是否匹配；用 `--verbose` 看传输层日志定位。
5. **多设备同时烧录蓝屏**：PC/Hub 供电与性能不足，官方手册亦有同样提示。

官方手册全文见 AiBurn 安装目录下的 `aiburn_manual.pdf`。
